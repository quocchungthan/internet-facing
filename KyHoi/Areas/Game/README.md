# Game — vận hành phòng

Xiangqi và caro 3x3 cùng engine. Vote bằng kéo quân hoặc chạm hai ô; mũi tên dày theo số người chọn. Chỉ đội đến lượt vote, lần hợp lệ cuối của mỗi IP được tính. Lượt trống đi ngẫu nhiên hợp lệ; hết thời gian trận hòa; host mở lại ván khi cần. Đây là luật thay thế chế độ chờ và tự mở ván cũ.

Kiểm tra luật mẫu bằng npm test; chưa chứng nhận đầy đủ luật lặp thế/đuổi quân giải đấu. Xem project architecture và acceptance-tests.
